# Data Quality Prompts

Specialized MCP prompts for data quality development workflows in the Payments Data Platform.

## Available Prompts

### 🧪 Test Suggestion Generator
**File**: `test_suggestion_generator_prompt.md`
**Purpose**: Expert guidance for creating compliant data quality tests and monitoring rules

### 📊 Data Quality Analyst  
**File**: `data_quality_analysis_prompt.md`
**Purpose**: Expert analysis of test files for compliance and effectiveness

### 🎯 Dual-Path Architecture Guidance
**File**: `dual_path_architecture_guidance.md`
**Purpose**: Comprehensive guidance for choosing between PySpark tests and JSON DQ Framework rules

### 🛠️ Azure DevOps AI Workflow Guide
**File**: `azure_devops_ai_workflow_guide.md`
**Purpose**: Comprehensive AI-assisted development workflow with MerlinBot integration, automated testing, and programmatic PR management

## Usage

These prompts are accessible via MCP clients through the `/mcp.pdp-development-mcp.` prefix:

- `/mcp.pdp-development-mcp.test_suggestion_generator` - Create new tests/rules
- `/mcp.pdp-development-mcp.data_quality_analyst` - Analyze existing tests  
- `/mcp.pdp-development-mcp.dual_path_dq_guidance` - Get architecture guidance
